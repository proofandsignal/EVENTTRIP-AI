# Partner access and revenue gate

All candidate partner statuses: RESEARCH / NOT APPROVED. No accounts, API rights, tracking links or contractual commissions are confirmed by this repository.

| Candidate | Planned use | What must be verified |
| --- | --- | --- |
| Travelpayouts | Flights/hotels | Approval, approved linking, feed rights, attribution and commission rules |
| Booking.com | Hotels | Affiliate acceptance, API/feed entitlement, price conditions |
| Expedia Group | Hotels/luxury | Account approval, data usage and conversion reporting |
| Marriott | Premium hotels | Approved program, brand use and qualifying booking rules |
| Fever | Events/experiences | Affiliate approval, event feed, link attribution and restrictions |
| Tiqets / GetYourGuide | Experiences | Separate approval and content rights |
| Ticketmaster | Concerts | Ticket affiliate program distinct from discovery API |

Before the first real booking CTA:
1. Confirm each selected provider's current official terms and approval; record evidence.
2. Confirm exact permitted tracking links and redirection hosts; use HTTPS allowlists.
3. Validate quote source, age, scope, taxes, currency and booking conditions.
4. Publish affiliate disclosure and required privacy/consent information.
5. Verify a tracked click through the partner's permitted reporting mechanism.
6. Only count a booking or commission if the partner confirms it; subtract fees, cancellations and costs.

Outreach kit: project description, target markets, planned user journey, product URL when available, actual traffic if any, and partner contact address. Never invent traffic metrics.
